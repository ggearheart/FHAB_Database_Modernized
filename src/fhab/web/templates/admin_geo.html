Authoritative geo boundaries

Load the authoritative boundary layers and assign HUC12, County, Regional Water Board and Water Body Type to every geocoded station by point-in-polygon. These feed the crosswalk export's County / HUC12 / Regional_Water_Board / Water_Body_Type (and the watershed-scale Water_Body_Name fallback) for lab samples that aren't tied to a report.

  • HUC12 — USGS Watershed Boundary Dataset (12-digit subwatershed), CA subset.
  • County — CA State Geoportal county boundaries.
  • Regional board — CA Water Boards Regional Board Boundaries (RB 1–9).
  • Water body type — USGS NHD Waterbody polygons (LakePond / Reservoir / SwampMarsh / …), CA subset. Stations inside a waterbody polygon are typed; river/stream sites are left unset.

Fetched live from the agency ArcGIS services (needs outbound network + curl). Existing rows are upserted; nothing is deleted. Re-run any time the published boundaries change or after ingesting new stations.
